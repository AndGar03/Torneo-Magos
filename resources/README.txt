=============================================
INSTRUCCIONES PARA AGREGAR IMÁGENES
=============================================

Para que las imágenes de los magos se muestren en el duelo, coloque los archivos:

1. mago_a.png - Imagen del mago del lado izquierdo
2. mago_b.png - Imagen del mago del lado derecho

FORMATO RECOMENDADO:
- Tamaño: 200x200 píxeles o similar
- Formato: PNG con transparencia
- Las imágenes se redimensionarán automáticamente

EJEMPLO:
Si quiere usar imágenes personalizadas, reemplace los archivos:
- resources/mago_a.png
- resources/mago_b.png

Por defecto, el programa mostrará un mensaje indicando dónde colocar las imágenes.
Las imágenes solo se mostrarán si los archivos existen en este directorio.
